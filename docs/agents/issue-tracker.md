# Issue tracker

Use the existing GitHub repository `immeasurablematt/well-and-good-websites`.

- Read issues with `gh issue list` and `gh issue view NUMBER`.
- Read pull requests with `gh pr list`, `gh pr view NUMBER`, and `gh pr diff NUMBER`.
- Create issues only when the task needs tracked follow-up. Small, single-session work may use a brief in `docs/` and one pull request.
- Use structured arguments or a body file for issue and pull request text.
- Preserve the user's publication and branch-cleanup instructions in CLAUDE.md and the active task.

Specs and decision records live in `docs/`. This is a single static-site repository, not a monorepo.
